Five steps, from outreach that happened to a report any leader can pick up.

## Open Reach-Out

Destination: reach-out

Reach-Out is under My Work in the sidebar. Check the list first: if another leader has already started this week's report for the same outreach, open it and choose **Edit** to add to it instead.

## Add a report

Choose **Add report**. It opens in the editor, dated today. Change **Date** if the outreach belongs to another day.

## Write what happened

Give it a **Title** and write the **Report** in plain prose, with a blank line between paragraphs. It saves as you type. Remember every leader can read it.

## Save it

Choose **Save report**. The report opens for reading, named as **Reported by** you.

## Ask, if you need something

If the outreach needs something from leadership, use *Does this need anything from leadership?* under the report. Otherwise leave it as information. Home now counts this week's Reach-Out report as written.
