### Write one

1. Open Reach-Out and choose **Add report**. A report dated today opens in the editor.
2. **Date** — the day the outreach belongs to. Change it if you are writing up an earlier week.
3. **Title** — for example *Weekly reach-out*. A report without one is listed as *Untitled report*.
4. **Report** — write what happened in plain prose. Leave a blank line between paragraphs; nothing else is formatted.
5. Choose **Save report**. The report opens for reading.

The report saves as you type — the editor shows **Saving…** and **Saved**. **Save report** makes sure the last of it has landed before it takes you back. If saving fails, it keeps you in the editor so nothing is lost.

### Change it later

Open the report and choose **Edit**. Any leader may do the same — see [Contributors](topic:reach-out.contribute).

### Discard or delete

- A report with no title and nothing written offers **Discard** at the bottom of the editor. It is removed at once.
- Once something is written, the button reads **Delete report** and asks you to confirm. The report and its comments go with it, and there is no undo.

Only the leader who started a report can delete it. For anyone else, the delete is refused.

Print a report from **Printable view** on the report.
