1. Open [Leadership Reports](destination:leadership-reports) and choose **New report**.
2. Pick **Write report here**, or **Link existing document** when the writing already lives in a document. The report is created as a Draft and opens for editing.
3. Give it a title where it says _What is this report?_
4. Fill in the row under the title. None of these is a closed list — you can type anything:
   - **Type** — suggestions include Leader's Progress Report, Evaluation / Assessment and Ministry / Operations. Choosing Leader's Progress Report on an empty report fills in its form; writing already there is never replaced.
   - **About** — a person, or a few words.
   - **Related to** — a ministry, or a few words.
   - **Period** — for example _September 2026_.
5. Set **Who can read this** and **Discussion**, and tick **Confidential** only if the report must be handled that way. With Named people or Shared, pick the people under _Also visible to_.
6. Add tags with **+ tag** and Enter.
7. Write. The toolbar has bold, italic, underline, links, headings, lists, checklists, quotes and dividers, plus **Mark as decision** and **Follow-up**. For a linked report, choose the document instead.
8. Choose **Done**. Everything saves as you type.

To write about a meeting, start from the note instead: **Write a report from this meeting** creates the Draft with the meeting's title and a link back to it. See [Write a report from a meeting](topic:meeting-notes.write-report).

When it is ready, move it on with the stage buttons. See [Report stages](topic:reports.statuses).

> A report does not ask anything of anybody. If you need something from leadership, use _Does this need anything from leadership?_ on the report page — see [Ask leadership for something](topic:asks.raise).
