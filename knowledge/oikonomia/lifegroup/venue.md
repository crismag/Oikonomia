A venue is a place the church meets — a home or a room. Venues are **reused**: every gathering at the same home points to the same venue, so it is chosen from a list rather than typed afresh each week.

### In the schedule

1. Open **LifeGroup**.
2. In the gathering's **Where** column, start typing the place's name.
3. Choose it from the suggestions. Only a chosen venue is saved — a half-typed name is not.
4. If the place is not in the list, finish typing its name and leave the field (or press Enter). Choose **Add “…” as a new venue**, and it is added and chosen.

### On the gathering's page

1. **Open** the gathering and choose **Edit details**.
2. Under **Where**, choose the venue — or type a new name and choose **Add “…” as a new venue**.
3. Choose **Save changes**.

### Who may change it

The gathering's leaders and campus oversight. While nobody has claimed the gathering, any leader may set it.

### Worth knowing

- If the place is not offered, it has not been added as a venue yet. Any leader can add it by name as above; an administrator can add its type and more under Administration. Check the list first, so the same home is not added twice under two spellings.
- A venue added while scheduling is named for the whole church, not only this gathering.
- **Set the venue** on Home means you lead a gathering that still has no place. See [Unclaimed gathering and Set the venue](topic:lifegroup.names).
- The venue's host, when one is recorded, is shown on the gathering's page as **Hosted by**.
