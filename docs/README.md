## The policy these follow

**Documentation here describes the current product, and is written from the
source and from verified behaviour.** Where this documentation and the code
disagree, the code is right and the documentation is a bug.

Implementation plans, development audits, design explorations and historical
task lists are deliberately not kept here. They describe what was intended at
a moment in the past, and a reader cannot tell which parts still hold.
